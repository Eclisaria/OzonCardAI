## Детализация этапов

### ✅ Интерфейс

Создан базовый профессиональный интерфейс приложения: главное окно, меню, toolbar, status bar, боковая навигация и рабочая область на основе `QStackedWidget`.

### ⬜ Настройки приложения

Добавить UI для базовых настроек приложения без хранения токенов на первом шаге.

### ⬜ Менеджер конфигурации

Создать безопасный слой чтения и записи пользовательской конфигурации.

### ⬜ Логирование

Добавить единый механизм логирования действий приложения, ошибок и диагностической информации.

### ⬜ Wildberries API

Добавить официальный клиент Wildberries API после подготовки слоя конфигурации и безопасного хранения параметров подключения.

### ⬜ Просмотр товаров

Реализовать таблицу или карточный список товаров продавца, полученных из Wildberries.

### ⬜ Поиск

Добавить поиск по товарам, артикулам, названиям и другим доступным полям.

### ⬜ Фильтрация

Добавить фильтры по категориям, статусам, брендам и другим признакам.

### ⬜ AI

Подготовить слой AI-провайдеров и единый интерфейс генерации данных для карточек.

### ⬜ Генерация карточек

Реализовать генерацию названий, описаний, SEO, ключевых слов, характеристик и атрибутов Ozon.

### ⬜ Ozon Seller API

Добавить официальный клиент Ozon Seller API для создания и проверки черновиков карточек.

### ⬜ Массовое создание черновиков

Добавить сценарии пакетной обработки выбранных товаров и массового создания черновиков.

### ⬜ Просмотр ошибок

Добавить понятный интерфейс отображения ошибок API, валидации и AI-ответов.

### ⬜ История операций

Сохранять и показывать историю импорта, генерации, отправки и ошибок.

### ⬜ Настройки моделей ИИ

Добавить выбор AI-провайдера, модели и параметров генерации.

### ⬜ Экспорт

Добавить экспорт результатов обработки в удобные форматы.

### ⬜ Импорт

Добавить импорт данных из файлов или подготовленных шаблонов, если это потребуется бизнес-процессу.

### ⬜ Автообновление

Подготовить механизм проверки и установки обновлений приложения.
