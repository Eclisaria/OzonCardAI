# OzonCardAI

OzonCardAI — настольное приложение для Linux, которое поможет продавцам автоматизировать подготовку карточек товаров Ozon на основе уже существующих товаров Wildberries.

Проект разрабатывается на Python 3.12+ и PyQt6. На текущем этапе создан базовый каркас приложения: структура каталогов, точка входа и главное окно.

## План развития

1. Настройки приложения.
2. Подключение Wildberries API.
3. Просмотр и выбор товаров.
4. Интеграция с ИИ для генерации контента карточек.
5. Интеграция с Ozon Seller API.
6. Массовое создание черновиков карточек.

## Запуск

```bash
python main.py
```
