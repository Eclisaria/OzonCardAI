# OzonCardAI

OzonCardAI — профессиональное настольное приложение для Linux (Ubuntu), которое поможет продавцам автоматизировать подготовку карточек товаров Ozon на основе уже существующих товаров Wildberries.

Проект разрабатывается на Python 3.12+ и PyQt6. Сейчас реализован фундамент интерфейса: модульная структура, точка входа, главное окно, боковая навигация и заготовки страниц для будущих этапов.

## Текущий этап

На текущем этапе не реализуются Wildberries API, Ozon API, AI-интеграции, база данных, авторизация и настройки токенов. Код подготовлен так, чтобы эти возможности можно было добавлять постепенно без переработки архитектуры.

## Реализовано

- Главное окно на базе `QMainWindow`.
- Меню, панель инструментов и строка состояния.
- Левая панель навигации.
- Рабочая область на базе `QStackedWidget`.
- Отдельные страницы для основных будущих разделов приложения.
- Единый QSS-стиль без сторонних библиотек.

## План развития

1. Настройки приложения.
2. Подключение Wildberries API.
3. Просмотр и выбор товаров.
4. Интеграция с ИИ для генерации контента карточек.
5. Интеграция с Ozon Seller API.
6. Массовое создание черновиков карточек.

## Запуск

```bash
python3 main.py
```
